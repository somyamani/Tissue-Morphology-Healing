# Tissue-Morphology-Healing
Generative rule based model of cell fate decisions: codes and data

This repository includes codes used for generating all datasets used in this study as well as codes used to analyse this data and generate figures.
Files in this repository:
    CODES FOR SIMULATIONS AND ANALYSIS
1. stable_unstable_cells_neighborhoods5.py: Python code for simulating development of model's tissues across various model parameters. This code also analyses the morphological properties of these model generated tissues and saves all tissue developmental trajectories as well as analyses in user defined file locations.
2. model4_param.p : '.pickle' file where each row gives parameter values for tissue development by the code 'stable_unstable_cells_neighborhoods5.py'
3. analyse_SUCN5.py: Reads data generated by 'stable_unstable_cells_neighborhoods5.py', performs PCA on tissue morphological properties, separates model's tissues into 'sectors', calculates sector crossings during tissue development, simulates small perturbations (cell ablations), analyses recovery from perturbations.
4. optimal_sector_finder_SUCN5.py: dependency of 'analyse_SUCN5.py'
5. visualize_bodies.py: dependency of 'analyse_SUCN5.py'
6. analyse_SUCN5_VeryLargePerturb.py: Reads data generated by 'stable_unstable_cells_neighborhoods5.py', simulates very large perturbations (cell ablations), analyses recovery from perturbations.
